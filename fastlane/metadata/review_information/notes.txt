Zeitkonto is free, with every feature unlocked. This version sells nothing: there are no in-app purchases, no subscriptions and no paywall. (The app contains StoreKit code for a later paid version; in this build it is switched off and never offers a purchase.)

NO ACCOUNT, NO NETWORK
There is no account and no login, so no demo account is needed. The app makes no network requests of its own. This version does not offer iCloud sync. There is no analytics, no tracking, no ads and no third-party code.

PERMISSIONS
Notifications only, and only when the user turns a reminder on. The optional "location" field on a day is text the user types: the app never asks for location permission and links no location framework.

TO SEE THE MAIN FEATURES QUICKLY
Sites > + > enter a name > Crew > add two names. Back on the site, tick who was there; the day is written to the calendar too. Site > ... > Export shows the monthly sheet for the site's director (PDF / Excel / CSV). Settings > Pay > enter an hourly rate to see earnings on the calendar and in Insights.
